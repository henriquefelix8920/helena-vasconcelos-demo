# Helena Vasconcelos — Cinematic Nutrition Experience

Landing page demonstrativa para uma profissional fictícia de nutrição. O projeto foi criado como peça de portfólio para demonstrar direção de arte, copy, narrativa visual, responsividade e interações frontend.

> **Importante:** Helena Vasconcelos é uma personagem fictícia. Este site não representa uma profissional real e não deve ser apresentado como se apresentasse credenciais, resultados, depoimentos ou dados de atendimento reais.

## Estrutura

- `index.html` — conteúdo e estrutura semântica das oito seções.
- `styles.css` — identidade visual, layout responsivo e animações.
- `script.js` — menu móvel, revelações no scroll, parallax discreto, FAQ e configuração de contato.
- `assets/images/` — fotografias finais a serem adicionadas.
- `assets/videos/` — vídeos finais a serem adicionados.
- `ASSETS.md` — inventário e instruções dos materiais audiovisuais.

## Como visualizar

Este é um site estático: não exige banco de dados, API, chaves ou dependências de instalação.

Para publicar, conecte este repositório a um serviço de hospedagem estática compatível, como Vercel. O arquivo `index.html` está na raiz do projeto.

## Contato

O projeto não possui canal real de contato configurado. Em `script.js`, configure `CONTACT.whatsapp` (somente dígitos, incluindo código do país) ou `CONTACT.email` somente quando houver dados autorizados da profissional.

## Movimento e acessibilidade

As animações são implementadas com CSS e JavaScript nativos, com suporte a `prefers-reduced-motion`. O site não depende de bibliotecas de animação pagas nem de serviços externos de runtime.
