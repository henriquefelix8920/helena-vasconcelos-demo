# 3. Regras de exportação e consistência

## Imagens
- Preferir WebP; JPG também é aceitável.
- Não renomear PNG/JPG para .webp sem converter o formato.
- Se a ferramenta gerar PNG/JPG, manter a extensão verdadeira. Informe os nomes finais para que os caminhos do site sejam atualizados.
- Exportar sem texto, sem moldura, sem assinatura e sem marca d'água.
- Preferir compressão e dimensão adequadas à web; evitar imagens gigantes desnecessariamente.

## Vídeos
- MP4 com codec H.264, sem trilha sonora.
- 1080p é suficiente para a primeira versão.
- 24 ou 30 fps.
- 6–10 segundos.
- Sem texto ou logotipo embutido.
- Usar movimento de câmera suave e uma só tomada.
- Se possível, criar loop com início e fim visualmente compatíveis.
- Não gerar fala: vídeos de fundo devem funcionar sem áudio.

## Como enviar ao GitHub pelo Chromebook

1. Abra o repositório `helena-vasconcelos-demo`.
2. Abra a pasta `assets/images` ou `assets/videos`.
3. Use **Add file → Upload files**.
4. Faça upload do arquivo com o nome e a extensão corretos.
5. Faça commit na branch `main`.

Se o GitHub não permitir enviar para uma pasta vazia, use **Add file → Create new file**, digite o caminho completo e crie um pequeno arquivo de texto, ou faça o upload do primeiro material na raiz do repositório e depois mova-o pela interface web.

**Não altere o HTML ainda.** Depois de subir os arquivos, envie o link do repositório e os nomes/formatos que foram gerados. Eu atualizo os caminhos, faço a integração dos vídeos, testo o fallback e ajusto os recortes para desktop e celular.

Helena é uma personagem fictícia. Use apenas material criado para ela ou devidamente licenciado. Não use rosto, voz ou aparência de uma nutricionista real sem autorização expressa. Não apresente a personagem como profissional real e não invente credenciais, pacientes, depoimentos ou resultados clínicos.
